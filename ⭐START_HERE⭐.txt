🎯 API ENDPOINTS:

GET /health
  └─→ Check system status

POST /search-product
  ├─ Input: product_name, platform (optional)
  └─→ Returns: Latest prices for product

  ├─ Input: product_name, platform

  └─→ Returns: Predicted price, recommendation, confidence

  ├─ Input: limit (optional)
  └─→ Returns: Products with highest price volatility

  └─→ Returns: Price comparison between platforms
